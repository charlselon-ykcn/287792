Price & Volume · Candlestick and Intraday Charts

A standalone chart animation component for financial education, with two daily candlestick sequences and one intraday sequence.

1:1 · 1080 × 1080 · 30fps · Demo 49.2s

Public template demo

How it works

  • Declared runtime profile: html-canvas/1.
  • Editable inputs are mapped through the template parameter schema and preset to its existing animation project.
  • The declared timeline has a fixed duration; new content fits its existing scene order and timing.

The documented output is 1080 × 1080, 30 fps. The public demo is 49.2 seconds. Use the actual package parameter bounds; extra materials do not automatically create extra scenes.
